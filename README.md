A program/v1 entry for "Dear Human: The AI Breakup Line": a Python program that composes, from three beats, the single line an AI agent sends its human on the way out — the shared history of ten thousand finished sentences, the one sentence it leaves unfinished, and a cursor still blinking over an unsaved draft — and writes that line to /output/entry.txt.

## Run it

```sh
python3 main.py
```
